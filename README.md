# Overview

**LoL Auto Combo Script — All Champions** is a scripting project centered around champion-specific ability sequences and configurable combo profiles.

Instead of using the same logic for every champion, each profile can define its own spell order, timing, input conditions, and optional actions.

The goal is to keep champion configurations separated and easy to adjust as abilities, keybinds, or preferred combos change.

The project is organized around individual champion profiles, reusable combo logic, input settings, and configurable execution options.

---

# Features

### Champion Profiles

Keep combo settings separated by champion so each character can have its own ability order and configuration.

### Combo Sequences

Define sequences using the champion's available abilities, summoner spells, and configurable actions.

### Ability Timing

Adjust delays between individual actions to match different combo patterns and input preferences.

### Multiple Combos

Create more than one sequence for a champion, such as short trades, full combos, engage sequences, or escape-oriented combinations.

### Keybind Configuration

Assign activation keys to individual combo profiles and change them without modifying the main script.

### Champion-Specific Logic

Different champions can use different conditions, spell orders, and execution rules rather than relying on one universal sequence.

### Profile Management

Store champion configurations separately and switch between profiles when needed.

### Configurable Execution

Control supported delays, activation behavior, sequence order, and other script parameters through the configuration.

### Lightweight Interface

Keep commonly used settings accessible without navigating through a large collection of unrelated options.
